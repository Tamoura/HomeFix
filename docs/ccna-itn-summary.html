01

Configure switches and end devices to provide access to local and remote network resources

إعداد الـ switches والأجهزة الطرفية للوصول للموارد المحلية والبعيدة

Networking Today — الأساسيات

  • مكونات الشبكة: End devices (PC, laptop, phone, printer, server) — المصدر أو الوجهة للرسالة، وIntermediary devices (switch, router, firewall, wireless AP) — بتوصّل وتوجّه، وNetwork media (copper, fiber, wireless).
  • NIC = كارت الشبكة، Port/Interface = المدخل اللي بيتوصل فيه الكابل.
  • Topology: Physical = مكان الأجهزة والكابلات فعليًا، Logical = الـ addressing scheme ومسار البيانات.
  • أنواع الشبكات: SOHO, LAN, WAN, Internet, Intranet (داخلي للموظفين), Extranet (وصول محدود لشركاء/عملاء).
  • طرق الاتصال بالإنترنت: منزلي → Cable, DSL, Cellular, Satellite, Dial-up. شركات → Dedicated Leased Line, Metro Ethernet, Business DSL (SDSL), Satellite.

خصائص الشبكة الموثوقة (4 characteristics)

Trends الحديثة

  • BYOD — أي جهاز، أي مكان، أي محتوى.
  • Online collaboration وVideo communication (Webex, telepresence).
  • Cloud computing — أنواعه: Public (متاح للكل), Private (لمؤسسة واحدة), Hybrid (خليط), Community (لمجموعة ليها نفس المتطلبات مثل الرعاية الصحية).
  • Powerline networking — نقل البيانات على أسلاك الكهرباء، وWireless ISP (WISP) للمناطق الريفية.

02

Explain how physical and data link layer protocols support the operation of Ethernet in a switched network

بروتوكولات الطبقة الفيزيائية وطبقة ربط البيانات وعمل الإيثرنت

Protocols & Models

  • عناصر أي اتصال: Source → Channel → Destination. وقواعد الاتصال: Message encoding, formatting & encapsulation, size, timing (access method, flow control, response timeout), delivery options (unicast / multicast / broadcast).
  • وظائف البروتوكولات: Addressing, Reliability, Flow control, Sequencing, Error detection, Application interface.
  • منظمات المعايير: ISO (نموذج OSI), IEEE (802.3 Ethernet, 802.11 WLAN), IETF (RFCs), IANA/ICANN (IPs & domains), EIA/TIA (الكابلات), ITU-T.

Encapsulation = إضافة الـ headers من الأعلى للأسفل، وDe-encapsulation = إزالتها من الأسفل للأعلى.

Physical Layer

  • 3 معايير: Physical components, Encoding (تحويل البتات لنمط — Manchester, 4B/5B, 8B/10B), Signaling (تمثيل البت كهربائيًا/ضوئيًا/راديو).
  • Bandwidth = السعة النظرية (bps/Kbps/Mbps/Gbps) · Throughput = المعدل الفعلي · Goodput = بيانات المستخدم المفيدة فقط · Latency = التأخير.
  • Copper: يتأثر بـ EMI/RFI وCrosstalk وAttenuation — لذلك بنستخدم اللف المزدوج (twisting) والتدريع.

أنواع كابلات UTP

  • Straight-through: أجهزة مختلفة — PC↔Switch, Switch↔Router.
  • Crossover: أجهزة متشابهة — Switch↔Switch, PC↔PC, PC↔Router, Router↔Router.
  • Rollover (console): PC↔Console port.
  • معايير الترتيب: T568A وT568B. الـ straight نفس المعيار على الطرفين، الـ crossover معيار مختلف.
  • Categories: Cat3 (تليفون) → Cat5e (1G) → Cat6/6a (10G) → Cat7/8.

الألياف الضوئية Fiber

  • SMF: نواة صغيرة، ليزر، مسافات طويلة جدًا (100+ كم) — للـ long-haul.
  • MMF: نواة أكبر، LED/VCSEL، حتى ~550م — داخل الـ campus/data center، فيه modal dispersion.
  • الموصلات: ST, SC, LC, Duplex LC.
  • مميزات على النحاس: مسافة أطول، bandwidth أعلى، مناعة كاملة ضد EMI/RFI، لا تُنصت عليه بسهولة. عيوب: تكلفة وأدوات ومهارة أعلى.

Wireless

  • معايير 802.11: a/b/g/n/ac (Wi-Fi 5)/ax (Wi-Fi 6) — تعمل على 2.4 GHz و/أو 5 GHz.
  • معايير أخرى: 802.15 Bluetooth, 802.16 WiMAX, Zigbee.
  • مكونات الـ WLAN: Wireless AP + Wireless NIC. العيوب: تداخل، أمان أقل، وسط مشترك (shared medium) → half-duplex.

Data Link Layer

  • طبقتان فرعيتان: LLC (802.2) — بتتعامل مع طبقة الشبكة وتحدد نوع البروتوكول، وMAC (802.3 / 802.11) — encapsulation + media access control.
  • WAN topologies: Point-to-Point, Hub-and-Spoke, Mesh. LAN topologies: Star, Extended Star, Bus, Ring.
  • Duplex: Half-duplex — إرسال أو استقبال (hubs، wireless)، Full-duplex — الاتنين في نفس الوقت (switches).
  • Media Access Control: CSMA/CD للإيثرنت القديم (اكتشاف التصادم)، CSMA/CA للـ WLAN (تجنّب التصادم). في الشبكات المبدّلة full-duplex الحديثة مفيش تصادمات أصلًا.
  • حقول الـ frame: Start indicator · Addressing · Type · Control · Data · FCS/CRC للكشف عن الأخطاء · Stop indicator.

Ethernet Switching

الحد الأدنى 64 bytes والأقصى 1518 bytes. أصغر من 64 = runt، أكبر من 1518 = giant. الـ jumbo frames بتوصل 9000 bytes.

MAC Address

  • 48 bit = 12 hex، محروق في الـ NIC (BIA). أول 6 hex = OUI (رقم المُصنّع)، آخر 6 hex = رقم فريد للجهاز.
  • Unicast لجهاز واحد · Broadcast = FF:FF:FF:FF:FF:FF · Multicast يبدأ بـ 01-00-5E لـ IPv4 و33-33 لـ IPv6.
  • MAC مقابل IP: الـ MAC عنوان محلي بيتغير عند كل hop، والـ IP عنوان منطقي بيفضل ثابت من المصدر للوجهة. ARP بيربط IPv4 بـ MAC، وND/NDP بيعمل نفس الدور في IPv6.

عمل الـ Switch

  • Learn: بيقرأ الـ source MAC ويضيفه للـ MAC address table مع رقم البورت. Forward: بيدوّر على الـ destination MAC — لو موجود يبعت للبورت المحدد، لو مش موجود يعمل flood لكل البورتات ما عدا الوارد منه.
  • طرق التمرير: Store-and-forward (يستقبل الـ frame كامل ويتحقق من الـ FCS — الأدق، وهو اللي بتستخدمه Cisco)، وCut-through (يمرر بعد قراءة الـ destination MAC — الأسرع؛ منه fast-forward وfragment-free).
  • Buffering: port-based memory أو shared memory.
  • Collision domain: كل بورت في السويتش = collision domain مستقل. Broadcast domain: كل الـ switch (أو الـ VLAN) = broadcast domain واحد — الـ router هو اللي بيقسّمها.
  • Auto-MDIX بيكتشف نوع الكابل ويعدّل تلقائيًا فمش محتاج تفرّق بين straight و crossover.

03

Configure routers to enable end-to-end connectivity between remote devices

إعداد الراوترات لتحقيق اتصال من طرف لطرف بين أجهزة بعيدة

النظري

  • وظيفة الراوتر: يفصل بين الـ broadcast domains ويوجّه الـ packets بناءً على destination IP. عند كل hop بيعمل de-encapsulate للـ frame، يفحص الـ IP header، يقرر المسار، ثم يعمل encapsulate بـ frame جديد بعناوين MAC جديدة.
  • مكونات الراوتر: CPU · RAM (running-config, routing table, ARP cache — متطايرة) · ROM (bootup instructions + POST) · NVRAM (startup-config) · Flash (IOS image).
  • Boot process: POST → تحميل الـ bootstrap → تحميل الـ IOS → تحميل الـ startup-config.
  • Default gateway = عنوان الـ interface على الراوتر في نفس شبكة الجهاز — من غيره الجهاز مش هيوصل لأي شبكة تانية.
  • Path determination: الراوتر بيدوّر على أطول تطابق longest prefix match. لو فيه أكتر من مسار بيختار الأقل metric، ولو التساوي بيستخدم Administrative Distance للترجيح بين البروتوكولات.

04

Create IPv4 and IPv6 addressing schemes and verify network connectivity between devices

تصميم مخططات عنونة IPv4 و IPv6 والتحقق من الاتصال

IPv4

  • 32 bit مكتوبة dotted decimal. الـ subnet mask بيفصل جزء الشبكة عن جزء المضيف عن طريق عملية AND المنطقية.
  • كل شبكة فيها 3 أنواع عناوين: Network address (كل بتات المضيف أصفار)، Host addresses، Broadcast address (كل بتات المضيف واحدات).
  • أنواع البث: Unicast (لواحد) · Broadcast (للكل — 255.255.255.255 محدود، أو broadcast الشبكة) · Multicast (لمجموعة — 224.0.0.0/4).

Subnetting

  • عدد الشبكات الفرعية = 2n حيث n = عدد البتات المستعارة. عدد المضيفات الصالحة = 2h − 2 حيث h = بتات المضيف المتبقية.
  • VLSM = تقسيم بأطوال مختلفة لتقليل الهدر — ابدأ دائمًا من الشبكة الفرعية الأكبر ثم الأصغر.
  • وصلة point-to-point بين راوترين محتاجة /30 (عنوانان صالحان) — أو /31 في التصاميم الحديثة.

IPv6

  • ليه IPv6؟ نفاد عناوين IPv4، وIoT، ومعالجة أبسط في الراوترات بدون NAT.
  • التعايش: Dual stack (الاتنين مع بعض) · Tunneling (IPv6 داخل IPv4) · Translation / NAT64.

تركيب الـ GUA: Global Routing Prefix (/48) + Subnet ID (16 bit) + Interface ID (64 bit). مفيش broadcast في IPv6 — استُبدل بالـ multicast.

طرق الحصول على عنوان IPv6

  • SLAAC — الجهاز يبني عنوانه من الـ prefix اللي في رسالة الـ RA، ويكوّن الـ Interface ID إما بـ EUI-64 (إدخال FFFE في نص الـ MAC وقلب بت الـ U/L) أو برقم عشوائي.
  • Stateless DHCPv6 — الـ prefix من الـ RA، وباقي المعلومات (DNS مثلًا) من سيرفر DHCPv6.
  • Stateful DHCPv6 — كل شيء من سيرفر DHCPv6 (شبيه بـ DHCPv4).
  • ICMPv6 NDP: رسائل RS/RA لاكتشاف الراوتر، وNS/NA لتحليل العناوين (بديل ARP) وDAD للتأكد من عدم تكرار العنوان.

ICMP والتحقق من الاتصال

  • رسائل مشتركة: Echo request / Echo reply · Destination unreachable · Time exceeded (انتهاء الـ TTL). في IPv6 تُضاف رسائل الـ NDP.
  • منهج الاختبار: ping 127.0.0.1 (الـ stack المحلي) → ping العنوان المحلي → ping الـ default gateway → ping وجهة بعيدة → traceroute لتحديد أين ينقطع المسار.

Explain how the upper layers of the OSI model support network applications

كيف تدعم الطبقات العليا في نموذج OSI تطبيقات الشبكة

Transport Layer (Layer 4)

  • الوظائف: تتبع المحادثات لكل تطبيق، تقسيم البيانات segmentation، إعادة التجميع، وmultiplexing عن طريق أرقام المنافذ.
  • الـ Socket = IP + Port. الـ socket pair بيحدد المحادثة بالكامل بين طرفين.

TCP — موثوق (20 bytes header)

  • Connection-oriented: 3-way handshake — SYN → SYN,ACK → ACK.
  • الإنهاء: FIN → ACK → FIN → ACK (أربع رسائل).
  • الموثوقية: sequence numbers لإعادة الترتيب، acknowledgements وإعادة الإرسال عند الفقد، SACK لإعادة إرسال المفقود فقط.
  • Flow control: نافذة متغيرة sliding window + window size لمنع إغراق المستقبل، وMSS لأقصى حجم بيانات.
  • Congestion avoidance: تقليل حجم النافذة عند اكتشاف ازدحام.
  • الاستخدام: HTTP/HTTPS, FTP, SMTP, SSH.

UDP — سريع (8 bytes header)

  • Connectionless — بدون handshake وبدون ضمان وصول أو ترتيب.
  • الوحدة اسمها datagram؛ إعادة الترتيب مسؤولية التطبيق.
  • overhead أقل بكتير → مناسب للـ real-time.
  • الاستخدام: DNS, DHCP, TFTP, VoIP, video streaming, SNMP.

  • Presentation (6): ترميز/تنسيق البيانات (GIF, JPEG, MPEG)، الضغط، والتشفير.
  • Session (5): إنشاء وإدارة وإنهاء الجلسات بين التطبيقات.
  • Client/Server — سيرفر مركزي يقدّم الخدمة. Peer-to-Peer (P2P) — كل جهاز يعمل كعميل وسيرفر في نفس الوقت (BitTorrent, Direct Connect) — لا مركزية لكن أمان أضعف.

DNS — سجلات وهيكل

  • أنواع السجلات: A عنوان IPv4 · AAAA عنوان IPv6 · NS سيرفر الأسماء · MX سيرفر البريد · CNAME اسم مستعار.
  • الهرمية: Root → TLD (.com, .net, .org, .eg) → النطاقات الفرعية. لو السيرفر مش عارف الإجابة بيسأل سيرفر أعلى.

DHCPv4 — دورة DORA

  • Discover (broadcast من العميل) → Offer (عرض من السيرفر) → Request (العميل يقبل) → Acknowledge (تأكيد وبدء مدة الـ lease).
  • لو فشل الـ DHCP الجهاز بياخد عنوان APIPA 169.254.x.x ومش هيوصل لبرّه الشبكة المحلية.

06

Configure a small network with security best practices

إعداد شبكة صغيرة وفق أفضل الممارسات الأمنية

تصميم الشبكة الصغيرة

  • معايير اختيار الأجهزة: التكلفة، عدد وسرعة المنافذ، قابلية التوسّع (expandability — fixed أم modular)، مميزات نظام التشغيل، الـ redundancy.
  • عوامل التخطيط: أنواع الترافيك (voice/video/data)، بروتوكولات الشبكة، أمن الشبكة، والنمو المستقبلي.

التهديدات الأمنية

أنواع الهجمات

  • Malware: Virus (يحتاج تشغيل من المستخدم)، Worm (ينتشر ذاتيًا)، Trojan (متخفّي في برنامج شرعي)، Ransomware, Spyware, Adware.
  • Reconnaissance: استطلاع وجمع معلومات (ping sweeps, port scans).
  • Access attacks: password attacks, trust exploitation, port redirection, man-in-the-middle.
  • DoS / DDoS: إغراق الجهاز أو الوصلة لمنع الخدمة عن المستخدمين الشرعيين.
  • Social engineering: Pretexting, Phishing, Vishing, Tailgating, Shoulder surfing.

وسائل التخفيف

  • Backup, Upgrade, Update, Patch بشكل دوري.
  • AAA: Authentication (من أنت؟) · Authorization (ماذا يُسمح لك؟) · Accounting (ماذا فعلت؟).
  • Firewalls: packet filtering, application filtering, URL filtering, stateful packet inspection (SPI).
  • Endpoint security: antivirus/antimalware + host-based firewall + IPS.
  • كلمات مرور قوية: 8 خانات على الأقل، خليط أحرف/أرقام/رموز، بدون كلمات قاموسية، وتغيير دوري.

Troubleshoot connectivity in a small network

استكشاف أعطال الاتصال في شبكة صغيرة وإصلاحها

منهجية استكشاف الأعطال — 7 خطوات

  • 1. تحديد المشكلة · 2. وضع نظرية للسبب المحتمل · 3. اختبار النظرية · 4. وضع خطة عمل · 5. تنفيذ الحل · 6. التحقق من كامل وظائف النظام · 7. توثيق النتائج والإجراءات.

أساليب الاستكشاف

  • Bottom-up — ابدأ من الطبقة الفيزيائية للأعلى (مفيدة عند الشك في مشكلة كابل).
  • Top-down — ابدأ من التطبيق للأسفل (عند الشك في مشكلة برمجية).
  • Divide-and-conquer — ابدأ من طبقة وسطى (عادة Layer 3 بـ ping) وحدد الاتجاه.
  • Follow-the-path · Substitution (استبدال المكوّن) · Comparison (مقارنة بإعداد سليم) · Educated guess.
